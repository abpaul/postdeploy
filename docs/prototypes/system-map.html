Explainer

PostDeploy target-state topology

One Phoenix app, one Postgres, one job system. Ash owns the domain; OTP owns concurrency; Oban owns durable work; Postgres owns truth. Cloudflare fronts the edge and Analytics Engine holds recent telemetry.

Click any building for its role, size and the files that implement it. Toggle a trace path (left) to follow a real control/data flow end to end.

Barrios (floor colour)

Clients — the three first-party SDKs.
Cloudflare — edge, Analytics Engine, outbound email.

AWS — the infra it runs on: EC2 host, ECR, RDS, S3.
External — Stripe, alert sinks.
