# console and auth screens are not. Auth pages have no unique content to
# rank for, and a sign-in form outranking a guide is a worse result for
# everyone.

# Every AI agent is listed and allowed on purpose, in three kinds:
#   search and answer: OAI-SearchBot, Claude-SearchBot, PerplexityBot
#   fetch on a user's request: ChatGPT-User, Claude-User, Perplexity-User
#   model training: GPTBot, ClaudeBot, Google-Extended, Applebot-Extended
# Google-Extended and Applebot-Extended only limit AI model use. Google
# Search and AI Overviews follow the Googlebot rules, which this file allows.
