01 — WHY BILLOW FEELS AIRY

Six rules, extracted.

Studied from the live pages — home, pricing, help. Airiness is composition, not margin size. These rules govern every public PostDeploy surface.

1 · One idea per viewport

Each section carries a single claim and a single artifact. Nothing competes. Sections may be tall and mostly empty as long as the one idea is unmissable.

2 · Narrow words, wide product

Copy never exceeds ~52ch; product surfaces run 75–100% of the container. The tension between a thin text column and a broad visual is what reads as "air".

3 · Two type sizes do the work

A large display size against a calm 15–17px body, almost nothing in between. Hierarchy comes from scale contrast, not from boxes, rules or color.

4 · Surfaces barely separate

White on near-white, 1px borders, generous radius. Shadow exists only under product frames — the one thing allowed to float.

5 · Density is delegated

The page stays sparse because product frames carry the detail. Marketing never re-explains what the screenshot already shows.

6 · Scroll is the navigation

The fold is ignored; each scroll stop is a complete thought. CTAs repeat quietly instead of shouting once.

02 — FOUNDATIONS

Brand is chartreuse. State is green.

Identity and status are separated on purpose: Pantone 2297 C marks what is PostDeploy, Pantone 354 C marks what is operational. They never swap jobs.

brand — Pantone 2297 C

#C0DF16 · rgb(192,223,22)

Identity, logo accent, selected state, active navigation, the primary button (with ink text — 11.9:1), limited chart emphasis. Never for "healthy", never body text on white.

brand · brand-tint · brand-wash · brand-deep (text-safe 5.9:1)

operational — Pantone 354 C

#00B140 · rgb(0,177,64)

Up, available, success, passing checks, uptime history. Semantic partners:
operational #00B140 degraded #E8960C failure #D92D20 info #2E62E8

State is always dot + word, never color alone.

Public type — Lastik + Open Runde

Run on signals, not vibes.

display · Lastik 600 (standing in: Bricolage Grotesque) · hero + major headings only

Body, nav, buttons, pricing, help, public status and changelog set in Open Runde — soft terminals, friendly without being toylike.

body · Open Runde 400–700 · 15–17px / 1.6

07 — CHART LIBRARY

One visual language for every number.

The shared contract: titles state the insight, value axes start at zero, deploys and incidents draw as labeled annotations that never obscure data, series are labeled directly (legend only when multi-series), tooltips repeat x/y plus release context, related charts share time range and filters, and every chart offers "view as table". Chartreuse = emphasis, green/amber/red = state, gray = context — never color alone.

CONTRAST LEDGER — WCAG AA

Headlines #171B12 on white16.4:1pass Body #5A6352 on white6.3:1pass Muted metadata #6E7864 on white4.6:1pass Ink on chartreuse (primary button)11.9:1pass Brand-deep #69790D on brand-wash4.7:1pass Status text: #00753B · #9A5B07 · #B42318 on white≥5.3:1pass Dark widgets #A9B49B on #20261B7.0:1pass

Fixed in this audit: the muted-text token shipped at 8A9284 (3.4:1 — fail) and has been darkened to 6E7864 (4.6:1) across every surface in this file. Chartreuse remains a fill and highlight only, never a text color on white.

FOCUS · KEYBOARD · MOTION

Focus is a 2px #2E62E8 ring at 2px offset on every interactive element, including chart ticks and widget links — shown live on the sign-in password field in 06. Tab order follows reading order; menus are arrow-keyed; dialogs trap focus and close on Esc. Every chart offers "view as table". State is always dot + word, never color alone. prefers-reduced-motion collapses all transitions to opacity; nothing loops except the live-status pulse, and even that stops.

RULES THAT SURVIVE BREAKPOINTS

Nav becomes a full-screen sheet with 48px rows. Hero metrics reflow 4→2×2; charts go full-bleed with x-labels reduced to endpoints while thresholds and deploy markers keep their labels. Tables pivot to key/value stacks; the comparison table gets a sticky plan switcher. The OAuth consent screen becomes a full-height sheet. Widgets are fluid to 240px. Copy never drops below 15px, targets never below 44px, and the display face steps 60→31px rather than shrinking line-length past ~34ch.
